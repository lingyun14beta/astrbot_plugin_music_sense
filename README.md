# astrbot_plugin_music_sense

让 Bot 听懂音乐——通过 Gemini 原生多模态音频理解，分析群里分享的音频文件的情感、氛围与风格。

## 功能

- 分析音频文件的情感基调、氛围、风格和节奏感
- 消息中的音频文件自动缓存，无需引用即可按序号分析
- 支持自动分析模式：收到音频立刻调用 Gemini，结果可注入对话上下文
- 支持指令触发和 LLM 工具自动触发
- 指令触发可使用独立的分析提示词
- 本地文件直接读取，远程文件按需下载
- 分析结果缓存，重复分析不消耗 API

## 使用方式

### 指令触发

发送 `/分析音频`，附带或引用音频文件：

```
/分析音频
/分析音频 这首歌适合什么场景？
```

如果没有附带或引用文件，Bot 会列出对话中缓存的音频文件，请用序号指定：

```
/分析音频 1
/分析音频 1 这首歌适合什么场景？
```

### LLM 工具自动触发

开启配置中的「启用 LLM 工具调用」后，Bot 提供三个工具：

| 工具 | 说明 |
|------|------|
| `analyze_current_audio` | 分析当前消息或引用消息中的音频 |
| `list_audio_files` | 列出对话中所有缓存的音频文件 |
| `analyze_audio_by_number` | 按序号分析指定音频 |

发送音频后与 Bot 对话，Bot 会自动判断是否需要分析。

### 自动分析 + 上下文注入

开启「自动分析音频」后，收到音频文件时会在后台自动调用 Gemini 分析，无需等待指令。

如果同时开启「注入分析结果到对话上下文」，分析结果会以 `[音乐感知]` 的形式在下一次 LLM 请求中自动注入，Bot 可直接感知音乐内容而无需调用工具。

## 支持的音频格式

mp3、wav、flac、m4a、aac、ogg

## 配置说明

### 添加 API 接入方

插件支持多个接入方，每个接入方对应一个 Gemini API 来源。

**Gemini 官方接口**

| 字段 | 说明 |
|------|------|
| 供应商名称 | 自定义标识，如 `gemini-official` |
| API Key | 在 [Google AI Studio](https://aistudio.google.com/apikey) 获取 |
| 模型名称 | 推荐 `gemini-2.0-flash` |
| 超时时间 | 建议不低于 120 秒 |

**OpenAI 兼容中转站**

| 字段 | 说明 |
|------|------|
| 供应商名称 | 自定义标识 |
| API Key | 中转站提供的访问密钥 |
| Base URL | 中转站地址，如 `https://xxx.com/v1` |
| 模型名称 | 按中转站实际支持的模型填写 |
| 超时时间 | 建议不低于 120 秒 |

> 中转站需支持 Gemini `generateContent` 接口且支持音频输入。

### 分析设置

**分析模型**

格式为 `供应商名称/模型名称`，供应商名称需与上方配置中的名称完全一致（区分大小写）。留空时自动使用第一个接入方。

例如：`gemini-official/gemini-2.0-flash`

**其他配置项**

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 分析系统提示词 | Gemini 分析指令，自动分析和 LLM 工具触发时使用 | 内置提示词 |
| 指令触发使用不同提示词 | 开启后可单独配置 `/分析音频` 的提示词 | 关闭 |
| 指令触发提示词 | 仅 `/分析音频` 指令触发时使用 | 同分析系统提示词 |
| 启用 LLM 工具调用 | 开启后 Bot 可主动分析 | 开启 |
| 最大文件大小 | 超过直接拒绝 | 20 MB |
| 支持的音频格式 | 仅列表内格式会被缓存 | mp3/wav/flac/m4a/aac/ogg |
| 自动分析音频 | 收到本地音频文件时自动分析 | 关闭 |
| 注入分析结果到对话上下文 | 自动分析的结果追加到对话上下文（需开启自动分析） | 关闭 |
| 调试模式 | 输出详细日志，方便排查 | 关闭 |
