# astrbot_plugin_music_sense

让 Bot 听懂音乐——通过 Gemini 原生多模态音频理解，分析群里分享的音频文件的情感、氛围与风格，并将结果注入对话上下文。

## 功能

- 分析音频文件的情感基调、氛围、风格和节奏感
- 支持显式指令触发和 LLM 工具自动触发两种模式
- 支持 Gemini 官方 API 和 OpenAI 兼容中转站
- 支持引用消息中的音频文件

## 使用方式

### 指令触发

在发送命令的同时附带音频文件，或引用一条含音频文件的消息：

```
/分析音频
/分析音频 这首歌适合什么场景？
```

命令词后面可以附加追问，Bot 会在分析音频的同时结合你的问题作答。

### LLM 工具自动触发

开启配置中的「启用 LLM 工具调用」后，当你发送音频文件并与 Bot 对话时，Bot 会自动分析音频内容并融入回复，无需手动输入指令。

## 支持的音频格式

mp3、wav、flac、m4a、aac、ogg

## 配置说明

### 添加 API 接入方

插件支持同时配置多个接入方，每个接入方对应一个 Gemini API 来源。

**Gemini 官方接口**

| 字段 | 说明 |
|------|------|
| 供应商名称 | 自定义标识，用于在「分析模型」中引用，如 `gemini-official` |
| API Key | 在 [Google AI Studio](https://aistudio.google.com/apikey) 获取 |
| 模型名称 | 推荐 `gemini-2.0-flash` |
| 超时时间 | 建议不低于 120 秒 |

**OpenAI 兼容中转站**

| 字段 | 说明 |
|------|------|
| 供应商名称 | 自定义标识，用于在「分析模型」中引用 |
| API Key | 中转站提供的访问密钥 |
| Base URL | 中转站地址，如 `https://xxx.com/v1` |
| 模型名称 | 按中转站实际支持的模型填写 |
| 超时时间 | 建议不低于 120 秒 |

> 中转站需要支持 Gemini `generateContent` 接口（非 OpenAI Chat Completions 接口）且支持音频输入，否则分析会失败。

### 分析设置

**分析模型**

格式为 `供应商名称/模型名称`，其中供应商名称必须与上方接入方配置中填写的名称**完全一致**（区分大小写）。

例如，接入方名称填写了 `gemini-official`，模型为 `gemini-2.0-flash`，则此处填写：

```
gemini-official/gemini-2.0-flash
```

留空时自动使用第一个接入方。

**其他配置项**

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 分析系统提示词 | 发给 Gemini 的分析指令 | 内置提示词 |
| 启用 LLM 工具调用 | 开启后 Bot 可主动分析，无需显式指令 | 开启 |
| 最大文件大小 | 超过此大小的音频将被拒绝 | 20 MB |
| 支持的音频格式 | 只有列表内的格式会被处理 | mp3/wav/flac/m4a/aac/ogg |
